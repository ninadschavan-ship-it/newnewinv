NINAD & NEHA — SCROLL WEDDING INVITATION

This is a static HTML/CSS/JS website (not TanStack/Vite/React). It avoids the previous missing-router build error.

PUBLISH ON VERCEL
1. Upload the contents of this folder to the ROOT of a new GitHub repository. index.html must be at the top level, with the images folder beside it.
2. In Vercel, import the repository.
3. Framework Preset: Other
4. Build Command: leave EMPTY / override OFF
5. Output Directory: leave EMPTY / override OFF
6. Install Command: leave EMPTY / override OFF
7. Deploy.

If Vercel has already detected TanStack Start, change Framework Preset to Other and turn off the Build Command override (or clear it). Do not use `bun run build` for this static site.
